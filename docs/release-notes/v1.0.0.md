**Your devices. One glance.** BatTray shows the battery level of your wireless mouse, keyboard, headset and game controllers right on the Windows taskbar: the device icon next to its percentage.

*Español abajo.*

## Download

Download **`BatTray-Setup-1.0.0.msi`** below and run it. It installs for your user only (no administrator rights) and includes a user guide (Start menu → *BatTray User Guide*).

> Windows may show *"Windows protected your PC"* because the installer is new and not code-signed yet. Click **More info → Run anyway**.

Requirements: Windows 11, or Windows 10 version 2004 or later, 64-bit.

## What's in 1.0

- **Taskbar widget** with each device's icon and percentage, coloured green / amber / red, on every monitor's taskbar. It never covers your app buttons.
- **Detail panel** (left-click) and **menu** (right-click), plus a tray icon that is always available.
- **Low battery alerts** at 15 %.
- **Bluetooth** devices that report their battery to Windows, **Xbox** and **PlayStation** controllers.
- **2.4 GHz USB receivers**: Logitech (Unifying, Bolt, Lightspeed), Razer, SteelSeries, Corsair, HyperX, Glorious, Lamzu, Attack Shark, MonsGeek, Akko, Keychron, Redragon, ATK, VXE, VGN, Dareu, Rapoo, Ajazz, Darmoshark, MCHOSE and receivers that follow the standard HID battery report.
- **Devices without battery data**: set the level yourself, or let BatTray estimate it from how long you use the device.
- **Customize devices**: rename them and pick an icon from the built-in set, or upload your own image.
- Light and dark themes, any display scaling, start with Windows.

**Privacy:** BatTray never connects to the internet and only sends read-only battery queries to receivers it recognises.
